Obter chave da API

Requisitos para utilização

Para consumir a API você precisa de duas informações:

  1. Chave privada do ambiente — obtida no Painel de Controle. Vem codificada em base64 e precisa ser decodificada antes de assinar o JWT.
  2. Token público do usuário (jti) — retornado por POST /auth/login com o usuário e a senha do Painel de Controle.

Onde obter a chave privada

No Painel de Controle, siga o caminho:

Menu Superior Direito → Configurações da Conta → Interface API → Chave Privada

Abrir o Painel de Controle

Autenticação (JWT)

A API usa JWT (assinatura HS256). Com a chave privada e o jti em mãos, monte o token assim:

  1. Faça POST /auth/login e guarde o jti.
  2. Decodifique de base64 a chave privada do ambiente.
  3. Assine, com essa chave, o header { "typ": "JWT", "alg": "HS256" } e o payload { "jti": "…" }.
  4. Envie o token em todas as chamadas no header Authorization: bearer <jwt>.
